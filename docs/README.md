# docs

本目录保存 Search-R1 MiniLab 的设计文档、状态事实源、学习记录和实验复盘。

目录说明：

- `design/`：项目设计和路线，例如 [design/idea.md](design/idea.md)；reward shaping 版本、诊断和下一轮实验计划见 [design/reward_shaping_plan.md](design/reward_shaping_plan.md)。
- `learning/`：学习过程中的笔记和资料整理。
- `status/`：项目状态唯一事实源。
- `interview/`：后续 GPU、PyTRIO、rollout 或评测实验的面试复盘材料。

开始新任务前优先读取 `status/PROJECT_COMPLETED.md` 与 `status/PROJECT_TODO.md`。
